================================================================================
        SUSU MGT SYSTEM (Express Capital Savings) — API ENDPOINTS REFERENCE
================================================================================

  Base URL:      http://localhost:5000/api/v1
  Swagger Docs:  http://localhost:5000/api/docs
  Auth:          All protected endpoints require  Authorization: Bearer <token>

================================================================================
  🔴  ADMIN ENDPOINTS  (Role: ADMIN)
================================================================================

  All endpoints below require Admin authentication.

  ── Dashboard & Overview ──────────────────────────────────────────────────────

   1. GET    /admin/dashboard
             Get dashboard statistics (totals, pending counts)

  ── User Management ───────────────────────────────────────────────────────────

   2. POST   /admin/users
             Create a new staff account (WORKER or ADMIN)
             Body: { email, password, fullName, phone, role }

   3. GET    /users
             Get all users (paginated)
             Query: ?page=1&limit=20

   4. GET    /users/:id
             Get user by ID

   5. PATCH  /users/:id
             Update user details
             Body: { fullName?, phone?, ... }

   6. POST   /users/:id/approve
             Approve a pending user account
             Body: { remarks? }

   7. POST   /users/:id/suspend
             Suspend a user

   8. POST   /users/:id/activate
             Activate a user

   9. POST   /users/:id/deactivate
             Deactivate a user account

  ── Financial Oversight ───────────────────────────────────────────────────────

  10. GET    /admin/transactions
             Get all recent transactions
             Query: ?page=1&limit=20

  11. GET    /admin/worker-collections
             Get all worker cash collections
             Query: ?page=1&limit=20&workerId=<optional>

  12. GET    /admin/customer-deposits
             Get all customer deposits
             Query: ?page=1&limit=20&userId=<optional>

  13. GET    /admin/withdrawals
             Get all withdrawals
             Query: ?page=1&limit=20&userId=<optional>&workerId=<optional>

  14. GET    /admin/audit-logs
             Get audit logs
             Query: ?page=1&limit=20

  ── Withdrawal Processing ─────────────────────────────────────────────────────

  15. POST   /transactions/:id/approve
             Approve a withdrawal request
             Body: { remarks? }

  16. POST   /transactions/:id/confirm-payment
             Confirm withdrawal payment completion
             Body: { remarks? }

  17. POST   /transactions/:id/reject
             Reject a withdrawal request
             Body: { remarks? }

  ── Wallet Controls ───────────────────────────────────────────────────────────

  18. GET    /admin/wallets/:userId
             Get a specific user's wallet

  19. POST   /admin/wallets/:userId/lock
             Lock a user's wallet

  20. POST   /admin/wallets/:userId/unlock
             Unlock a user's wallet

  ── System Settings ───────────────────────────────────────────────────────────

  21. GET    /admin/settings
             Get all system settings

  22. PATCH  /admin/settings
             Create or update a system setting
             Body: { settingKey, settingValue, description? }

  ── Worker Session Management ─────────────────────────────────────────────────

  23. GET    /admin/worker-sessions
             Get worker sessions
             Query: ?page=1&limit=20&status=ACTIVE|ENDED

  24. POST   /admin/worker-sessions/:id/terminate
             Force terminate a worker session

  ── Admin Notifications ───────────────────────────────────────────────────────

  25. GET    /admin/notifications
             Get admin notifications
             Query: ?page=1&limit=20


================================================================================
  🟡  WORKER ENDPOINTS  (Role: WORKER)
================================================================================

  All endpoints below require Worker authentication.

  ── Session Management ────────────────────────────────────────────────────────

   1. POST   /workers/clock-in
             Clock in to start a work session
             Body: { deviceInfo?, ipAddress? }

   2. POST   /workers/clock-out
             Clock out to end a work session

   3. GET    /workers/session
             Get current active session info

  ── Cash Operations ───────────────────────────────────────────────────────────

   4. POST   /workers/cash-deposit
             Record a cash deposit for a customer
             Body: { userId, amount, description? }

   5. GET    /workers/collections
             Get own cash collections
             Query: ?page=1&limit=20

  ── Withdrawal Processing ─────────────────────────────────────────────────────

   6. POST   /transactions/:id/worker-confirm-payment
             Confirm a cash withdrawal payment
             Body: { remarks? }

   7. GET    /workers/withdrawals
             Get worker processed withdrawals
             Query: ?page=1&limit=20

  ── Worker Notifications ──────────────────────────────────────────────────────

   8. GET    /workers/notifications
             Get worker notifications
             Query: ?page=1&limit=20


================================================================================
  🟢  CUSTOMER ENDPOINTS  (Authenticated Users)
================================================================================

  All endpoints below require a valid Bearer Token.

  ── Payments (Paystack) ───────────────────────────────────────────────────────

   1. POST   /payments/paystack/initialize
             Initialize a Paystack deposit
             Body: { amount }

   2. GET    /payments/paystack/verify/:reference
             Verify a Paystack transaction

  ── Transactions ──────────────────────────────────────────────────────────────

   3. GET    /transactions/me
             Get own transaction history
             Query: ?page=1&limit=20

   4. GET    /transactions/:id
             Get transaction details by ID
             (Admins can view any; customers only their own)

   5. GET    /transactions/withdrawals
             Get own withdrawal history
             Query: ?page=1&limit=20

   6. POST   /transactions/withdrawals
             Create a withdrawal request
             Body: { amount, method }

  ── Wallet ────────────────────────────────────────────────────────────────────

   7. GET    /wallets/me
             Get own wallet balance and status


================================================================================
  🔵  COMMON / PUBLIC ENDPOINTS
================================================================================

  ── Authentication (No Token Required) ────────────────────────────────────────

   1. POST   /auth/signup
             Register a new user
             Body: { email, password, fullName, phone, redirectTo? }

   2. POST   /auth/signin
             Sign in
             Body: { email, password }

   3. POST   /auth/verify-email
             Verify email with OTP
             Body: { email, token, type? }

   4. POST   /auth/resend-verification
             Resend verification email
             Body: { email, redirectTo? }

   5. POST   /auth/reset-password
             Request password reset
             Body: { email, redirectTo? }

  ── Authentication (Token Required) ───────────────────────────────────────────

   6. GET    /auth/me
             Get current authenticated user profile

   7. POST   /auth/signout
             Sign out

   8. POST   /auth/update-password
             Update password
             Body: { password }

  ── Profile (Any Authenticated User) ──────────────────────────────────────────

   9. GET    /users/profile
             Get current user profile details

  10. PATCH  /users/profile
             Update own profile
             Body: { fullName?, phone?, ... }

  ── Notifications (Any Authenticated User) ────────────────────────────────────

  11. GET    /notifications
             Get own notifications
             Query: ?page=1&limit=20

  12. GET    /notifications/unread-count
             Get unread notification count

  13. PATCH  /notifications/:id/read
             Mark a notification as read

  14. PATCH  /notifications/read-all
             Mark all notifications as read

  ── System ────────────────────────────────────────────────────────────────────

  15. GET    /
             Health check / Hello

  ── Webhook (Server-to-Server, No Token) ──────────────────────────────────────

  16. POST   /webhooks/paystack
             Paystack webhook handler
             Header: x-paystack-signature

================================================================================
  NOTES
================================================================================

  * All paginated endpoints support ?page=1&limit=20 query parameters.
    Default page is 1, default limit is 20.

  * Swagger interactive docs available at: http://localhost:5000/api/docs

  * The global API prefix is /api/v1 — all routes above should be
    prepended with this prefix.
    Example: GET /api/v1/admin/dashboard
